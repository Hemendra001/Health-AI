## 🌟 Overview & Key Highlights

- **Real-Time Prediction Engine**: Built a high-performance **FastAPI backend** paired with a responsive frontend to deliver real-time mental-health risk assessments based on user behavioral and daily-routine metrics.
- **Machine Learning Pipeline**: Architected end-to-end **Scikit-Learn preprocessing pipelines** with automated feature engineering, scaling, and outlier handling.
- **Model Training & Optimization**: Trained, validated, and tuned a **Random Forest Classifier** achieving high classification accuracy and robustness against class imbalances.
- **Data Scraping Pipeline**: Built an automated web-scraping pipeline to ingest supplementary training data, enriching feature representations.

---

## 🛠️ Tech Stack

- **Core**: Python 3
- **Framework**: FastAPI, Uvicorn
- **ML / Data Science**: Scikit-Learn, Random Forest, Pandas, NumPy
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/Hemendra001/Health-AI.git
cd Health-AI

# 2. Set up virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the API server
uvicorn main:app --reload
```
